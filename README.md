# 🎓 Pixel Sens – Learn With Fun

🚀 An AI-powered virtual learning platform that makes education interactive and engaging through hand gesture recognition, virtual whiteboard interaction, and Generative AI.

## 📌 About the Project

Pixel Sens is an AI-powered virtual whiteboard designed to provide a fun and interactive learning experience. It allows users to write and draw using real-time hand gestures through a webcam. The platform also integrates Generative AI to help users solve mathematical and subject-related questions.

🎯 The main goal of Pixel Sens is to make learning easier, more interactive, and accessible through AI and computer vision technologies.

## ✨ Features

- 🖐️ **Virtual Whiteboard:** Write and draw using hand gestures in front of a webcam.
- 📷 **Hand Gesture Recognition:** Real-time hand tracking using OpenCV and MediaPipe.
- 🤖 **AI Question Solving:** Get answers to mathematical and subject-related questions using the Gemini API.
- 📝 **Notes Management:** Save and access learning notes.
- 🎮 **Educational Games:** Interactive word-unscramble games to make learning enjoyable.
- 💡 **Interactive Learning:** Combines computer vision and Generative AI for an engaging learning experience.

## 🛠️ Technologies Used

- 🐍 **Programming Languages:** Python, JavaScript
- ⚙️ **Framework:** Django
- 👁️ **Computer Vision:** OpenCV, MediaPipe
- 🧠 **Generative AI:** Google Gemini API
- 🌐 **Frontend:** HTML, CSS, JavaScript

## 💻 Installation and Setup

Follow these steps to run the project locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/meetsarode/pixel-sens-learn-with-fun-.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd pixel-sens-learn-with-fun-
```

### 3️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run the Django Server

```bash
python manage.py runserver
```

### 7️⃣ Open in Browser

```text
http://127.0.0.1:8000/
```
